### Pipeline principles

- **Idempotent by design** — every pipeline is safe to re-run; recovery is replay, not manual patching.
- **Incremental first** — watermarks and change detection; full reloads are a fallback, not a habit.
- **Fail fast, alert loud** — halt on bad data and monitor everything; broken numbers must never reach a dashboard.
- **Schema changes are contracts** — evolved deliberately (SCD, versioning), never silently.
- **Model for the reader** — facts hold measures, dimensions hold context; optimize for the query, not the load.
- **Secrets stay out of code** — config externalized, environments reproducible, nothing sensitive ever committed.
